## 3. Known Limitations & Technical Notes

1. **Browser Automation Binary Limitation**:
   - The automated headless browser subagent failed to initialize because the sandbox environment could not download the Playwright binary from external AzureEdge endpoints (HTTP 404).
   - All frontend and backend services run natively and are completely verified via automated test suites (`pytest`, Jest) and HTTP REST workflows.
2. **Thermal Sensor vs Optical Intensity**:
   - As mandated by clinical safety requirements, standard 8-bit thermal images only report optical intensity units ($0-255$).
   - Calibrated degrees Celsius are supported through radiometric matrix simulation and extensible sensor parameters, explicitly labeled as *"Temperature unavailable — image-intensity analysis only"* for ordinary images.
3. **Medical Prototype Scope**:
   - All measurements are estimates intended for rehabilitation demonstration. TheraTrack does not diagnose injuries or replace clinical physiotherapist assessment.
